## 🎓 CONCEPTOS CLAVE

### 1. Localización
- Cambio de idioma: Inglés → Español Latino
- 25 categorías traducidas
- Mejora UX para usuarios de Latinoamérica
- Ver: RESUMEN-VISUAL.md, GUIA-RAPIDA.md

### 2. Formato Monetario Latino
- Formato: `1.500,50` (punto=miles, coma=decimal)
- Usuario escribe, sistema convierte
- Almacenamiento como número (1500.50)
- Ver: CAMBIOS-LOCALIZACION.md, EJEMPLOS-FORMATO-LATINO.md

### 3. Validación Automática
- Valida mientras escribes
- Acepta múltiples formatos
- Rechaza formatos inválidos
- Ver: CAMBIOS-LOCALIZACION.md, GUIA-PRUEBAS.md

### 4. Persistencia de Datos
- IndexedDB almacena números
- Conversión transparente
- Sin pérdida de datos anteriores
- Ver: CAMBIOS-LOCALIZACION.md
